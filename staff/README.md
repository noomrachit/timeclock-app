# ลงเวลาพนักงาน (หลายคน)

เซิร์ฟเวอร์ aiohttp + PostgreSQL — พนักงานตอกเวลาจากมือถือตัวเอง, แอดมินดูและสรุปรอบเงินเดือน

- หน้าพนักงาน: `/` (รหัสพนักงาน + PIN) — เปิดแอปแล้วเด้งถาม: ทำงาน (ตามกะ 1 คลิก) / ลา / ขาด / อื่นๆ (ใส่เวลาเอง)
  แก้ได้เฉพาะวันนี้ และแก้ไม่ได้ถ้าแอดมินแก้วันนั้นแล้ว
- หน้าแอดมิน: `/admin` (รหัสผ่านจาก `ADMIN_PASSWORD`) — แก้วัน: ทำงาน (ตามกะ) / แก้เวลา / ขาด / ลา (+ชม.ลาที่ได้เงิน) / วันหยุด
- กะ: อา–พฤ 06:00–16:00 · ศ 06:00–11:00 · ส หยุด (ลงทำงานไม่ได้)
- ค่าแรงต่อชั่วโมง: อา–พฤ 100%×8, ศ 100%×3 → 125%×2 → 150%×1 → 175%×1 → 200% ทุกชั่วโมงที่เหลือ
  ชั่วโมงปัดลงทีละ 30 นาที · ชั่วโมงลาที่แอดมินให้คิด 100%
- รอบเงินเดือน: วันที่ 21 ถึงวันที่ 20 ของเดือนถัดไป
- PIN ผิด 5 ครั้ง ล็อก 15 นาที

ตัวแปรที่ต้องตั้ง: `DATABASE_URL`, `ADMIN_PASSWORD` (อย่างน้อย 10 ตัว)
รัน: `pip install -r requirements.txt && python server.py`
