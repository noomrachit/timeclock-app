# ลงเวลา

PWA ลงเวลาเข้า-ออก เก็บในเครื่อง ใช้ออฟไลน์ได้

ติดตั้ง iPhone: เปิดด้วย Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม

Timezone: Asia/Jerusalem
กติกา: อา–พฤ 06:00–16:00 · ศ 06:00–11:00 · ส หยุด
รอบคิดเงิน: วันที่ 21 ถึงวันที่ 20 ของเดือนถัดไป (คำนวณอัตโนมัติ)
สำรองข้อมูล: ปุ่มส่งออก / นำเข้า ในแอป
